このサイトの使い方

OrangeMania の base アプリを購入したら、このガイドに沿ってAIと一緒にカスタマイズを進められます。制作者はChatGPTとClaudeを使用していますが、どちらのAIでも同じ手順で進めることができます。

進め方のコツ：まずはChatGPT/Claudeに相談を

Codex/Claude Codeも会話で進められますが、慣れないうちに思いつきのまま伝えると、意図が曖昧になり結果がブレやすくなることがあります。このサイトでは、先にChatGPTやClaudeで「何をどう変えたいか」を整理し、具体的な指示文を作ってもらってからCodex/Claude Codeに貼る進め方をおすすめしています。慣れてきたら、Codex/Claude Codeに直接相談する進め方に移っていただいて構いません。
